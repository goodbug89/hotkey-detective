⇧⌘4 を押しても何も起きない。どれかのアプリが奪っている — でもどれ？ macOS にはこれに答える API がなく、システム設定で尋ねる方法もありません。

組み合わせを押すだけ。答えと、そう判断した理由が出ます。

根拠を集め、重みを付ける

「このショートカットの持ち主は誰か」に唯一の正解となる情報源はありません。だから独立した信号を集め、 いま何に基づいているかを明示します。

システム

システムショートカット

macOS 自身のショートカット表 — システム設定の裏にあるまさにその表 — と、あなたが加えた変更を読みます。

確実
設定

アプリ設定

知っているアプリの設定ファイルを解析し、アプリ名だけでなく正確な動作まで特定します。

高 — アプリが起動していなければ下がる
スキャン

設定スキャン

よく使われる 2 つのショートカット保存形式を、どのアプリの設定からでも見分けます。見慣れないアプリが 自動的に見えなくなることはありません。

反応

反応

キーを押した後に実際に何が起きるかを観察します — ミリ秒単位でウインドウを開いたり前面に出たりするアプリを。

観察であって主張ではない

ホットキープローブ

Carbon のホットキー API に、その組み合わせがすでに押さえられているかを尋ねます。限界は下に正直に書きました。

観察のみ
判定

…そして判定

すべての主張は、その根拠を一緒に示します。ブラックボックスを信じるのではなく、自分で判断できるように。

5 つの結果 — 下を参照

答えは 1 つではなく 5 つ

ショートカットがきれいに白黒つくことは稀です。判定はどれだけ確かかまで伝えます。

confirmed

権威ある情報源がこの組み合わせを結び付けています。システム表がそう言ったか、起動中のアプリの設定がそう言ったかです。

likely

根拠は一方を指していますが確定しません — スキャンの一致か、登録の裏付けなしに反応しただけのアプリです。

contested

2 つ以上が同じ組み合わせを登録しています。ここに来た理由がまさにこれで、一覧の先頭に固定されます。

occupied

何かが握っていますが、誰かは特定できませんでした。実際には稀です — 理由は限界の節にあります。

free

何も見つかりませんでした。割り当てて構いません — 上と同じ但し書き付きで。

信頼できるものにしている区別

反応は、アプリがキーを受け取ったことを証明します。アプリがそれを 登録したことの証明ではありません。だから反応は持ち主を裏付けることはできても、覆すことはできません。

この規則がないと、⌘Space が「システムと Spotlight が争っている」と読めてしまいます。何の問題も ないのにです — Spotlight はそのシステムショートカットが開く先にすぎません。ここを取り違えることが 競合検出ツールを狼少年にする原因であり、ここでのすべての判定が自信たっぷりの一文ではなく 情報源を示す理由です。

あるいは推測そのものを省く

1 回ずつ調べるだけでなく、見えるショートカットをすべて並べます — システムの割り当て、既知のアプリ、 スキャン結果まで。競合は先頭に固定されます。

組み合わせやアプリ名で検索できます。ディープスキャンはサンドボックスアプリの設定まで読みます — macOS がアプリごとに許可を尋ねるため、既定ではオフです。

打鍵をどう扱うか

手短に言えば、1 つを見て、1 つを残し、何も送りません。

✓

リポジトリにネットワークコードはありません。何もアップロードされません。できないからです。

✓

キーボードタップは受信専用です。キーは観察するだけで横取りしません — 本来の持ち主がそのまま受け取ります。反応検知が機能する原理がこれです。

✓

記録も保存もしません。調べた後に残るキーのデータは、あなたが調べた組み合わせ 1 つだけです。

✓

権限は要求ではなく説明します。プローブにはアクセシビリティと入力監視の両方が必要です。受信専用タップに macOS が両方を求めるからです。

✓

権限がなくても動きます。制限モードでは組み合わせを手で選べば、設定ファイルだけで答えます。

✓

ソースは公開されています。MIT ライセンス — このページのすべての記述は確認できます。

できないこと

死角を隠す検出ツールは、ない方がましです。

Carbon のホットキープローブは他プロセスを見られない

RegisterEventHotKey は呼び出したプロセス内の競合しか報告しません。そのため「占有されているが 特定できない」という判定は事実上出ません。ホットキーを登録し、ウインドウを出さず、設定を 認識できない形式で保存するアプリは見えないままです。

システム機能名は韓国語以外では英語

macOS は自前の翻訳を読み取れない場所に持っています。勝手に作るとシステム設定の表示と食い違うため、 元の英語名をそのまま示します。

設定スキャンが認識する保存形式は 2 つ

KeyboardShortcuts ライブラリと MASShortcut 形式の辞書です。 独自形式のアプリには専用パーサーが必要です — 貢献を歓迎します.

インストール

macOS 14 以降が必要です。無料で、解除するものもありません。

Homebrew 推奨

アプリ内に更新機能がないため、最新に保つならこの方法です — あとは brew upgrade がやります。

brew install --cask \
goodbug89/tap/hotkey-detective

直接ダウンロード

公証済みのディスクイメージで 1 MB 程度です。開いてアプリを「アプリケーション」にドラッグしてください。
