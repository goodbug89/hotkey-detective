تضغط ⇧⌘4 فلا يحدث شيء. هناك تطبيق استحوذ عليه — لكن أيّها؟ لا يقدّم macOS أي واجهة برمجية تجيب عن ذلك، ولا يمكن معرفته من إعدادات النظام أيضًا.

يجمع HotkeyDetective الأدلة، ويصدر حكمًا، ويعرض معه أساس هذا الحكم:

```
⇧⌘4
حفظ صورة المنطقة المحددة (النظام) يستخدم هذا الاختصار
  ●●●●  النظام    اختصار النظام رقم 30 مفعّل بوصفه ⇧⌘4
```

## آلية العمل

لا يوجد مصدر واحد موثوق يحدد «مَن يملك هذا الاختصار»، لذا يجمع التطبيق إشارات مستقلة ويوازن بينها:

| المصدر | ما يثبته | القوة |
| --- | --- | --- |
| **اختصارات النظام** | جدول macOS نفسه يربط هذه التركيبة | مؤكد |
| **إعدادات التطبيق** | ملف إعدادات تطبيق معروف يربط هذه التركيبة | عالية (منخفضة إذا كان التطبيق غير مشغّل) |
| **فحص الإعدادات** | إعدادات التطبيق تطابق صيغة تخزين معروفة | متوسطة |
| **رصد الاستجابة** | فتح تطبيقٌ نافذةً أو انتقل إلى المقدمة فور الضغط | عالية |
| **اختبار الاختصار** | عملية ما تحتفظ بتسجيل اختصار Carbon | ملاحظة فقط |

الحكم يكون `مؤكد` أو `مرجّح` أو `متنازع عليه` أو `مشغول دون تحديد` أو `متاح`. كل ادعاء يعرض الأدلة التي يستند إليها، فتحكم بنفسك بدلًا من الوثوق بصندوق أسود.

ثمة تمييز مهم: **الاستجابة** تثبت أن التطبيق *تلقّى* المفتاح، لا أنه *سجّله*. الاستجابة قد تدعم المالك لكنها لا تنازعه أبدًا. بدون هذه القاعدة يبدو ⌘Space وكأن «النظام و Spotlight يتنازعان» رغم أن كل شيء سليم.

## التثبيت

يتطلب macOS 14 أو أحدث.

```bash
git clone https://github.com/goodbug89/hotkey-detective.git
cd hotkey-detective
Scripts/bundle.sh
open build/HotkeyDetective.app
```

يوقّع البناء بشهادة Developer ID إن وُجدت في سلسلة المفاتيح، وإلا فبتوقيع ad-hoc. تفقد نسخ ad-hoc أذوناتها مع كل إعادة بناء — راجع [BUILDING.md](../../BUILDING.md).

## الأذونات

يحتاج الاختبار إلى **تسهيلات الاستخدام** و**مراقبة الإدخال** معًا. يشترط macOS كليهما لالتقاط أحداث لوحة المفاتيح في وضع الاستماع فقط.

تُراقَب ضغطات المفاتيح دون اعتراضها أو تسجيلها أو تخزينها إطلاقًا. يُنشأ الالتقاط بوضع `.listenOnly` فيستمر المالك الحقيقي في تلقّي المفتاح — وعلى ذلك يقوم رصد الاستجابة تحديدًا. بعد الاختبار لا يبقى سوى التركيبة الواحدة التي بحثت عنها. لا يوجد في هذا المستودع أي شيفرة شبكة.

من دون الأذونات يعمل التطبيق في **الوضع المحدود**: تختار التركيبة يدويًا فيجيب اعتمادًا على ملفات الإعدادات وحدها.

## حدود معروفة

- **اختبار اختصار Carbon لا يرى العمليات الأخرى.** يبلّغ `RegisterEventHotKey` عن التعارض داخل عمليتك أنت فقط، لذا يكاد حكم «مشغول دون تحديد» يكون غير قابل للتحقق. التطبيق الذي يسجّل اختصارًا ولا يعرض نافذة ويخزّن إعداداته بصيغة غير معروفة يبقى غير مرئي.
- **أسماء وظائف النظام بالإنجليزية خارج الكورية.** يحتفظ macOS بترجماته في موضع لا نستطيع قراءته، وابتكار ترجمة خاصة بنا سيخالف ما تراه في إعدادات النظام.
- **يتعرّف فحص الإعدادات على صيغتَي تخزين فقط** (مكتبة `KeyboardShortcuts` وقواميس بنمط `MASShortcut`). التطبيقات ذات الصيغ الخاصة تحتاج محلّلًا مخصصًا — [المساهمات مرحّب بها](../../CONTRIBUTING.md).
