คุณกด ⇧⌘4 แล้วไม่มีอะไรเกิดขึ้น มีแอปหนึ่งแย่งมันไป — แต่แอปไหน? macOS ไม่มี API ที่ตอบเรื่องนี้ และในการตั้งค่าระบบก็ดูไม่ได้เช่นกัน

HotkeyDetective รวบรวมหลักฐาน ตัดสิน และแสดงเหตุผลให้ดูด้วย:

```
⇧⌘4
บันทึกภาพพื้นที่ที่เลือก (ระบบ) กำลังใช้อยู่
  ●●●●  ระบบ    ทางลัดระบบ #30 เปิดใช้งานเป็น ⇧⌘4
```

## หลักการทำงาน

ไม่มีแหล่งข้อมูลเดียวที่บอกได้ว่า «ใครเป็นเจ้าของทางลัดนี้» แอปจึงรวบรวมสัญญาณอิสระหลายอย่างแล้วชั่งน้ำหนัก:

| แหล่งที่มา | พิสูจน์อะไร | ความหนักแน่น |
| --- | --- | --- |
| **ทางลัดระบบ** | ตารางของ macOS เองผูกคีย์ผสมนี้ไว้ | แน่นอน |
| **การตั้งค่าแอป** | ไฟล์ตั้งค่าของแอปที่รู้จักผูกคีย์ผสมนี้ไว้ | สูง (ต่ำถ้าแอปยังไม่เปิด) |
| **สแกนการตั้งค่า** | การตั้งค่าของแอปตรงกับรูปแบบจัดเก็บที่รู้จัก | ปานกลาง |
| **ตรวจจับปฏิกิริยา** | หลังกดปุ่ม แอปเปิดหน้าต่างหรือขึ้นมาด้านหน้าทันที | สูง |
| **ทดสอบฮ็อตคีย์** | มีโปรเซสถือการลงทะเบียนฮ็อตคีย์ Carbon อยู่ | เป็นเพียงการสังเกต |

ผลตัดสินคือ `ยืนยัน` · `น่าจะใช่` · `ขัดแย้ง` · `ถูกใช้แต่ระบุไม่ได้` · `ว่าง` อย่างใดอย่างหนึ่ง ทุกข้อสรุปมีหลักฐานกำกับ คุณจึงตัดสินเองได้แทนที่จะเชื่อกล่องดำ

มีข้อแตกต่างสำคัญข้อหนึ่ง: **ปฏิกิริยา** พิสูจน์ว่าแอป *ได้รับ* ปุ่ม ไม่ใช่ว่าแอป *ลงทะเบียน* ปุ่มไว้ ปฏิกิริยาสนับสนุนเจ้าของได้ แต่ไม่มีวันโต้แย้งเจ้าของได้ ถ้าไม่มีกฎนี้ ⌘Space จะถูกอ่านว่า «ระบบกับ Spotlight กำลังแย่งกัน» ทั้งที่ไม่มีอะไรผิด

## การติดตั้ง

ต้องใช้ macOS 14 ขึ้นไป

```bash
git clone https://github.com/goodbug89/hotkey-detective.git
cd hotkey-detective
Scripts/bundle.sh
open build/HotkeyDetective.app
```

ตัวสร้างจะเซ็นด้วยใบรับรอง Developer ID ถ้ามีในพวงกุญแจ ถ้าไม่มีจะใช้การเซ็นแบบ ad-hoc บิลด์ ad-hoc จะเสียสิทธิ์ทุกครั้งที่สร้างใหม่ — ดู [BUILDING.md](../../BUILDING.md)

## สิทธิ์

การตรวจต้องใช้ทั้ง **การช่วยการเข้าถึง** และ **การตรวจสอบอินพุต** macOS กำหนดให้ต้องมีทั้งคู่สำหรับ event tap แป้นพิมพ์แบบฟังอย่างเดียว

การกดปุ่มถูกสังเกตเท่านั้น ไม่เคยถูกดักจับ บันทึก หรือจัดเก็บ tap ถูกสร้างด้วย `.listenOnly` เจ้าของตัวจริงจึงยังได้รับปุ่มตามปกติ — นั่นคือหลักการที่ทำให้การตรวจจับปฏิกิริยาทำงานได้ หลังการตรวจ ข้อมูลปุ่มที่เหลืออยู่มีเพียงคีย์ผสมเดียวที่คุณค้นหา ในที่เก็บโค้ดนี้ไม่มีโค้ดเครือข่ายใด ๆ

แม้ไม่ให้สิทธิ์ แอปก็ยังทำงานใน **โหมดจำกัด**: เลือกคีย์ผสมเองแล้วตอบจากไฟล์ตั้งค่าเท่านั้น

## ข้อจำกัดที่ทราบ

- **การทดสอบฮ็อตคีย์ Carbon มองไม่เห็นโปรเซสอื่น** `RegisterEventHotKey` รายงานการชนกันเฉพาะภายในโปรเซสของตัวเอง ผลตัดสิน «ถูกใช้แต่ระบุไม่ได้» จึงแทบไม่มีทางเกิดขึ้น แอปที่ลงทะเบียนฮ็อตคีย์ ไม่แสดงหน้าต่าง และเก็บการตั้งค่าในรูปแบบที่ไม่รู้จัก จะยังคงมองไม่เห็น
- **ชื่อฟังก์ชันระบบเป็นภาษาอังกฤษ ยกเว้นภาษาเกาหลี** macOS เก็บคำแปลของตัวเองไว้ในที่ที่เราอ่านไม่ได้ และถ้าเราแปลเองก็จะไม่ตรงกับที่คุณเห็นในการตั้งค่าระบบ
- **การสแกนการตั้งค่ารู้จักรูปแบบจัดเก็บสองแบบ** (ไลบรารี `KeyboardShortcuts` และดิกชันนารีแบบ `MASShortcut`) แอปที่ใช้รูปแบบเฉพาะต้องมีตัวแยกวิเคราะห์เฉพาะ — [ยินดีรับการมีส่วนร่วม](../../CONTRIBUTING.md)
