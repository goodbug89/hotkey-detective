คุณกด ⇧⌘4 แล้วไม่มีอะไรเกิดขึ้น มีแอปหนึ่งแย่งมันไป — แต่แอปไหน? macOS ไม่มี API ที่ตอบเรื่องนี้ และในการตั้งค่าระบบก็ไม่มีที่ให้ดู

ดาวน์โหลดสำหรับ macOS ติดตั้งด้วย Homebrew

หลักฐานเอียงไปทางหนึ่งแต่ยังไม่ชี้ขาด — อาจเป็นผลจากการสแกน หรือแอปที่มีปฏิกิริยาโดยไม่มีการลงทะเบียนรองรับ

contested

มีเจ้าของตั้งแต่สองรายขึ้นไปลงทะเบียนคีย์ผสมเดียวกัน นี่คือกรณีที่คุณมาหา และจะถูกปักไว้บนสุดของรายการ

occupied

มีบางอย่างถือครองอยู่ แต่ระบุไม่ได้ว่าคือใคร พบได้ยากในทางปฏิบัติ — เหตุผลอยู่ในหัวข้อข้อจำกัด

free

ไม่พบอะไรเลย กำหนดใช้ได้ — โดยมีข้อแม้เดียวกับข้างต้น

ข้อแยกแยะที่ทำให้เชื่อถือได้

ปฏิกิริยา พิสูจน์ว่าแอปได้รับปุ่มนั้น ไม่ได้พิสูจน์ว่าแอปลงทะเบียนปุ่มนั้น ปฏิกิริยาจึงสนับสนุนเจ้าของได้ แต่ไม่มีวันคัดค้านเจ้าของได้

หากไม่มีกฎนี้ ⌘Space จะถูกอ่านว่า “ระบบกับ Spotlight กำลังขัดแย้งกัน” ทั้งที่ไม่มีอะไรผิดเลย — Spotlight เป็นเพียงสิ่งที่คีย์ลัดของระบบเปิดขึ้นมา การเข้าใจกลับด้านตรงนี้คือสิ่งที่ทำให้เครื่องมือตรวจการชนกลายเป็น ตัวส่งสัญญาณเตือนลวง และเป็นเหตุผลที่ทุกคำตัดสินที่นี่แสดงแหล่งที่มา แทนที่จะทิ้งประโยคมั่นใจเพียงประโยคเดียว

หรือข้ามการเดาไปเลย

นอกจากการตรวจทีละคีย์ แอปยังแสดงคีย์ลัดทุกตัวที่มองเห็น — การผูกของระบบ แอปที่รู้จัก และผลการสแกน — โดยปักรายการที่ขัดแย้งไว้บนสุด

ค้นหาด้วยคีย์ผสมหรือชื่อแอป การสแกนเชิงลึก จะอ่านการตั้งค่าของแอปในแซนด์บ็อกซ์ด้วย — macOS จะขออนุญาตเป็นรายแอป จึงปิดไว้เป็นค่าเริ่มต้น

แอปทำอะไรกับปุ่มที่คุณกด

สรุปสั้นๆ: ดูหนึ่ง เก็บหนึ่ง ไม่ส่งอะไรเลย

✓

ในที่เก็บโค้ดไม่มีโค้ดเครือข่ายเลย ไม่มีอะไรถูกอัปโหลด เพราะทำไม่ได้ตั้งแต่ต้น

✓

การดักคีย์บอร์ดเป็นแบบฟังอย่างเดียว ปุ่มถูกสังเกตแต่ไม่ถูกดักจับ — เจ้าของตัวจริงยังได้รับตามปกติ นี่คือหลักการทำงานของการตรวจจับปฏิกิริยา

✓

ไม่บันทึกและไม่จัดเก็บ หลังการตรวจ สิ่งที่เหลืออยู่คือคีย์ผสมเดียวที่คุณเลือกค้นหาเท่านั้น

✓

สิทธิ์ถูกอธิบาย ไม่ใช่ถูกเรียกร้อง การตรวจต้องใช้ทั้งการช่วยการเข้าถึงและการตรวจสอบอินพุต เพราะ macOS กำหนดให้ต้องมีทั้งสองสำหรับการฟังอย่างเดียว

✓

ไม่มีสิทธิ์ก็ยังใช้ได้ ในโหมดจำกัด คุณเลือกคีย์ผสมเองแล้วแอปตอบจากไฟล์ตั้งค่าเพียงอย่างเดียว

✓

ซอร์สโค้ดเปิดเผย ใช้สัญญาอนุญาต MIT — ทุกข้อความในหน้านี้ตรวจสอบได้

สิ่งที่ทำไม่ได้

เครื่องมือตรวจที่ซ่อนจุดบอดของตัวเอง ยังแย่กว่าการไม่มีเลย

การตรวจแบบ Carbon มองไม่เห็นโปรเซสอื่น

RegisterEventHotKey รายงานการชนเฉพาะภายในโปรเซสที่เรียกใช้เท่านั้น ทำให้คำตัดสิน “ถูกใช้อยู่แต่ระบุไม่ได้” แทบไม่มีทางเกิดขึ้นจริง แอปที่ลงทะเบียนคีย์ลัด ไม่แสดงหน้าต่าง และเก็บการตั้งค่าในรูปแบบที่ไม่รู้จัก จะยังคงมองไม่เห็น

ชื่อฟังก์ชันของระบบเป็นภาษาอังกฤษ ยกเว้นภาษาเกาหลี

macOS เก็บคำแปลของตัวเองไว้ในที่ที่เราอ่านไม่ได้ การแต่งขึ้นเองจะขัดกับสิ่งที่คุณเห็นในการตั้งค่าระบบ จึงแสดงชื่อภาษาอังกฤษดั้งเดิมแทน

การสแกนรู้จักรูปแบบการเก็บเพียงสองแบบ

ไลบรารี KeyboardShortcuts และดิกชันนารีสไตล์ MASShortcut แอปที่ใช้รูปแบบเฉพาะของตัวเองต้องมีตัวแยกวิเคราะห์เฉพาะทาง — ยินดีรับการมีส่วนร่วม.
